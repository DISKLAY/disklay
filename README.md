# Тренажёр к коллоквиумам по анатомии

Статическое веб-приложение для подготовки к трём коллоквиумам. Выберите коллоквиум в шапке сайта:

1. **Остеология и артросиндесмология** — 211 вопросов.
2. **Миология** — 188 вопросов из «Миология 2025 by students».
3. **Спланхнология** — 254 вопроса из «Спланхнология ЛФ ПФ by students от 28.03.26».

Вопросы и варианты ответов перенесены из соответствующих баз, а ключ — по подсветке в PDF. Тексты и отмеченные ответы не заменяют проверку по учебным материалам; спорный ответ можно изменить в разделе «Ключ».

## Возможности

- **Тренировка** по темам с мгновенной проверкой, работой над ошибками и статистикой.
- **Экзамен первого коллоквиума** — 20 вопросов за 20 минут, случайная выборка по установленным квотам 11 разделов (2+2+2+2+2+2+2+1+2+2+1). В банке экзамена доступны все 211 вопросов: внутреннее основание черепа — № 110–117; остальные вопросы о черепе в целом отнесены к ближайшим разделам лицевого (№ 118–137) и мозгового (№ 138–140) черепа, а вопросы о размерах таза (№ 188–191) — к костям нижней конечности.
- Экзамены для второго и третьего коллоквиумов появятся после уточнения их формата.
- Редактирование, импорт и экспорт ключей; светлая и тёмная темы; работа офлайн.

Прогресс, правки ключей, история и незавершённые сессии сохраняются отдельно для каждого коллоквиума в браузере. При переключении коллоквиума экзаменационный таймер продолжает идти. Существующее сохранение первого коллоквиума остаётся доступным.

## Запуск

Откройте `index.html` в браузере или запустите статический сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Ключ ответов

Базовые ответы уже заполнены. Локальные исправления и импорт на странице «Ключ» имеют приоритет над базой. Номера соответствуют исходному PDF соответствующего коллоквиума; в первом коллоквиуме № 58 встречается дважды — второй обозначен 58а, а № 92 отсутствует.

Поддерживаемые форматы импорта:

```text
1: 1, 2, 4
2. 1 2 3 4
3 — а, в, д
4 = 135
{"5": [1, 3]}
```

Номера вариантов начинаются с 1; доступны также буквы `а/б/в/г/д/е` или `a/b/c/d/e/f`. При необходимости можно переключиться на нумерацию по порядку.

## Структура и проверка

- `js/data/questions.js`, `js/data/answers.js` — вопросы и ключ первого коллоквиума.
- `js/data/exam.js` — схема экзамена первого коллоквиума.
- `js/data/colloquium-2.js`, `js/data/colloquium-3.js` — вопросы, темы и ключи новых баз.
- `js/modules.js` — выбор банка; `js/core.js` — состояние и проверка; `js/views-*.js` — интерфейс.
- `scripts/import_colloquium_pdf.py` — воспроизводимый импорт из предоставленных PDF; для запуска нужен PyMuPDF, пути к PDF и выходному файлу указаны в комментарии скрипта.

Тесты запускаются командой `node --test tests/*.test.js`.

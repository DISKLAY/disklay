# Тренажёр к коллоквиуму по анатомии

Статическое веб-приложение для подготовки к коллоквиуму: **211 заданий** из PDF «Список заданий, модуль 1»
(нумерация сохранена как в исходном файле).

## Что умеет

- **Тренировка** — вопросы по выбранным темам с мгновенной проверкой и разбором: какие варианты верные, что пропущено, что лишнее.
- **Экзамен** — фиксированный формат: **20 вопросов за 20 минут** по плану из 11 разделов
  (2+2+2+2+2+2+2+1+2+2+1). Вопросы выбираются случайно из банка внутри каждого раздела,
  таймер, навигация по номерам и отложенная проверка после завершения. Вопросы о внутреннем
  основании черепа выбираются из заданий № 110–117. В разделе соединений нижней конечности
  учитываются вопросы о соединениях таза, но не вопросы о его размерах.
- **Работа над ошибками** — вопросы, где вы ошибались и ещё не закрепили ответ; можно отметить «выучено» или отработать отдельно.
- **Статистика** — освоено/изучено, точность, прогресс по 13 темам, история прохождений.
- **Ключ ответов** — импорт правильных ответов из текста или файла, ручная правка, экспорт, шаблон для заполнения.
- Светлая/тёмная тема, сохранение прогресса в браузере, работа офлайн, горячие клавиши `1`–`5` и `Enter`.

## Запуск

Без сборки: откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Ключ ответов

Ключ **уже заполнен**: 211 ответов перенесены из файла «База теста 1 коллоквиум.pdf»,
где верные варианты отмечены подсветкой. Проверка работает автоматически, режим самопроверки
не нужен.

Данные лежат в `js/data/answers.js` (объект `window.ANSWER_KEY`). Свои правки и импорт
на странице **«Ключ»** сохраняются в `localStorage` и имеют приоритет над базой — то есть
спорный ответ можно переопределить, не трогая файл.

В базе у вопросов от 1 до 4 верных вариантов (451 отмеченный вариант на 211 заданий).
Если ответ кажется спорным, отметьте его заново на странице «Ключ» — приложение будет
проверять по вашей версии.

Форматы импорта:

Поддерживаемые форматы:

```
1: 1, 2, 4
2. 1 2 3 4
3 — а, в, д
4 = 135
{"5": [1, 3]}
```

- номера вариантов — с 1;
- буквы `а/б/в/г/д` или `a/b/c/d/e` тоже подходят;
- `135` без разделителей читается как 1, 3, 5;
- если ключ нумерован не по номерам PDF, а по порядку (1…211), включите переключатель
  «Нумерация по порядку» в блоке импорта.

Вопрос **№ 58** в PDF встречается дважды — второй помечен как **58а**; вопроса **№ 92** в файле нет.

Если очистить ключ (кнопка «Удалить все ответы»), приложение вернётся к режиму самопроверки:
после ответа вы сами отмечаете, верно ли ответили, и эти оценки идут в статистику.

## Структура

```
index.html
css/styles.css
js/data/questions.js    база заданий (211 вопросов, 13 тем)
js/data/answers.js      ключ ответов из базы теста (211 ответов)
js/data/exam.js         план экзамена: 11 разделов, квоты вопросов (20 всего), 20 минут
js/core.js              состояние, парсер ключа, подсчёт, сессии
js/ui.js                иконки, тосты, модалки, тема
js/views-study.js       главная, настройка, прохождение, итоги
js/views-pages.js       ошибки, статистика, ключ, настройки
js/app.js               маршрутизация (#/train, #/exam, #/key, …)
```

Все данные (прогресс, история, ключ) хранятся только в `localStorage` браузера — сервер не нужен.

# Тренажёр к коллоквиуму по анатомии

Статическое веб-приложение для подготовки к коллоквиуму: **211 заданий** из PDF «Список заданий, модуль 1»
(нумерация сохранена как в исходном файле).

## Что умеет

- **Тренировка** — вопросы по выбранным темам с мгновенной проверкой и разбором: какие варианты верные, что пропущено, что лишнее.
- **Пробный экзамен** — случайные вопросы, таймер, навигация по номерам, проверка после завершения.
- **Работа над ошибками** — вопросы, где вы ошибались и ещё не закрепили ответ; можно отметить «выучено» или отработать отдельно.
- **Статистика** — освоено/изучено, точность, прогресс по 13 темам, история прохождений.
- **Ключ ответов** — импорт правильных ответов из текста или файла, ручная правка, экспорт, шаблон для заполнения.
- Светлая/тёмная тема, сохранение прогресса в браузере, работа офлайн, горячие клавиши `1`–`5` и `Enter`.

## Запуск

Без сборки: откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Ключ ответов

Правильные ответы лежат в `js/data/answers.js` (объект `window.ANSWER_KEY`) или импортируются
в приложении на странице **«Ключ»**. Импортированное хранится в `localStorage` и имеет приоритет.

Поддерживаемые форматы:

```
1: 1, 2, 4
2. 1 2 3 4
3 — а, в, д
4 = 135
{"5": [1, 3]}
```

- номера вариантов — с 1;
- буквы `а/б/в/г/д` или `a/b/c/d/e` тоже подходят;
- `135` без разделителей читается как 1, 3, 5;
- если ключ нумерован не по номерам PDF, а по порядку (1…211), включите переключатель
  «Нумерация по порядку» в блоке импорта.

Вопрос **№ 58** в PDF встречается дважды — второй помечен как **58а**; вопроса **№ 92** в файле нет.

Пока ключ не заполнен, приложение работает в режиме самопроверки: после ответа вы сами отмечаете,
верно ли ответили. Эти оценки идут в статистику.

## Структура

```
index.html
css/styles.css
js/data/questions.js    база заданий (211 вопросов, 13 тем)
js/data/answers.js      ключ ответов (по умолчанию пустой)
js/core.js              состояние, парсер ключа, подсчёт, сессии
js/ui.js                иконки, тосты, модалки, тема
js/views-study.js       главная, настройка, прохождение, итоги
js/views-pages.js       ошибки, статистика, ключ, настройки
js/app.js               маршрутизация (#/train, #/exam, #/key, …)
```

Все данные (прогресс, история, ключ) хранятся только в `localStorage` браузера — сервер не нужен.
